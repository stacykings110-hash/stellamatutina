# Portfolio Website of Stella Matutina Uwamahoro

This is a simple portfolio website made by Stella Matutina Uwamahoro (BIT20250314). It tells about me, what I am
learning and my project.

## Features

- About me section with my student details
- List of what I am learning
- Project section
- Goals section
- Plain page that opens in any browser

## How to run this project

The website is online here: https://github.com/stacykings110-hash/stellamatutina

To open it on your own computer, follow the steps below.

### Prerequisites

- A web browser like Chrome, Edge or Firefox
- Git installed on your computer

### Installation

1. Clone the repo:

   ```bash
   git clone hhttps://github.com/stacykings110-hash/stellamatutina
   ```

2. Open the project folder:

   ```bash
   cd stellamatutina
   ```

3. Double-click `index.html` to open it in your browser.
